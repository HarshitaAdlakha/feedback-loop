How I work[ECE → AI]

Every project is the same pipeline.

01 · sense

Read the signal

Telemetry, vitals, images, clinical text. ECE taught me to respect noise, sampling and the sensor before the model.

telemetrytime-seriesvision
02 · model

Find the pattern

XGBoost, LSTM and GRU, clinical BERT, causal graphs. Whatever the data supports, measured against a real baseline.

XGBoostLSTMBERT
03 · verify

Prove it can be trusted

Root causes, cited manual sections, SHAP and token attributions, calibrated uncertainty. Verification and validation is my research, so it is never an afterthought.

V&VXAIMBSE
04 · decide

A human signs

The system drafts the work order or the recovery step. A qualified person approves it. That boundary is a design decision.
